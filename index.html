Como funciona

3 passos para ter sua IA local.

Do zero ao assistente funcional em menos de 5 minutos. Sem Docker, sem configurações complexas.

PASSO 01

Instale o Ollama

Baixe o instalador oficial para macOS, Linux ou Windows. Ele cuida de tudo: runtime, drivers e dependências.

PASSO 02

Baixe um modelo

Execute ollama pull llama3.1 e aguarde. Modelos de 7–8B rodam bem em 16GB de RAM.

PASSO 03

Abra o OpenCode

Configure o provider como "ollama" e comece a conversar com seu modelo diretamente no terminal, com acesso ao seu código.

Instalação

Copie, cole, rode.

Comandos prontos para cada sistema operacional. Tudo via terminal — como desenvolvedor gosta.

📦 macOS / Linux
# 1. Instalar o Ollama $ curl -fsSL https://ollama.com/install.sh | sh # 2. Baixar um modelo (recomendado: llama3.1:8b) $ ollama pull llama3.1:8b # 3. Instalar o OpenCode $ npm install -g opencode # 4. Rodar! $ opencode --provider ollama --model llama3.1:8b ✓ pronto — assistente local ativo
🪟 Windows (PowerShell)
# Baixar o instalador oficial PS> irm https://ollama.com/install.ps1 | iex # Baixar modelo e iniciar PS> ollama pull llama3.1:8b PS> opencode --provider ollama

Dúvidas frequentes

Perguntas comuns.

Tudo que você precisa saber antes de começar.

Preciso de uma GPU potente? +
Não obrigatoriamente. Modelos de 7–8B rodam tranquilamente em CPU com 16GB de RAM. Uma GPU (mesmo integrada) acelera muito a geração, mas não é requisito. Para modelos acima de 30B, aí sim uma GPU dedicada com 16GB+ de VRAM é recomendada.
Posso usar em projetos comerciais? +
Sim! Modelos como Llama 3.1 e Qwen 2.5 têm licenças permissivas que permitem uso comercial. Sempre verifique a licença específica do modelo escolhido no repositório do Ollama.
Funciona no Windows? +
Sim, o Ollama tem suporte nativo ao Windows (incluindo aceleração por GPU NVIDIA e AMD). O OpenCode roda via Node.js, então funciona em qualquer sistema com Node 18+.
Posso treinar ou ajustar um modelo? +
O Ollama permite criar modelos customizados via Modelfile, ajustando system prompts, parâmetros e templates. Para fine-tuning real, você precisará de ferramentas como Unsloth ou LLaMA-Factory, e depois importar o resultado para o Ollama.
E se eu ficar sem internet? +
Funciona normalmente! Depois de baixar o modelo uma única vez, tudo roda 100% offline. Ideal para viagens, ambientes restritos ou simplesmente para não depender de conexão.
